# Pharaonic Community

The home for questions, ideas, and conversation around [Pharaonic](https://pharaonic.dev)'s open-source packages for PHP, Laravel, Livewire, and Filament.

This repository holds no package code. It is the source repository for the organization's discussions, so the conversation itself lives in **[Pharaonic Discussions](https://github.com/orgs/Pharaonic/discussions)**.

## Where to Go

| You want to… | Go to |
| --- | --- |
| Ask how to do something | [Q&A](https://github.com/orgs/Pharaonic/discussions/categories/q-a) |
| Suggest a new package or an early idea | [Ideas](https://github.com/orgs/Pharaonic/discussions/categories/ideas) |
| Share something you built | [Show and tell](https://github.com/orgs/Pharaonic/discussions/categories/show-and-tell) |
| Talk about anything else in the ecosystem | [General](https://github.com/orgs/Pharaonic/discussions/categories/general) |
| Follow releases and project news | [Announcements](https://github.com/orgs/Pharaonic/discussions/categories/announcements) |
| Report a confirmed bug or request a specific feature | Open an issue in [that package's repository](https://github.com/Pharaonic) |
| Correct a guide | Open an issue in [Pharaonic/guides](https://github.com/Pharaonic/guides/issues/new/choose) |
| Report a security vulnerability | Report it privately through that repository's **Security** tab, never in a discussion |

## Before You Post

1. Check the [package documentation](https://pharaonic.dev/packages) and the [guides](https://pharaonic.dev/guides).
2. [Search existing discussions](https://github.com/orgs/Pharaonic/discussions), because your question may already have an answer.
3. Remove API keys, `.env` values, and other private data from anything you paste.

See [CONTRIBUTING.md](CONTRIBUTING.md) for how to get a useful answer quickly, and [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) for the expectations that apply to every thread.
